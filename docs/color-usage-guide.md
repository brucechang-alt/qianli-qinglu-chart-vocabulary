# 千里青绿色彩使用指南

这套配色是面向现代屏幕的视觉转译，不是对宋代矿物颜料的科学测量或标准色复原。

## 核心角色

- **素绢 `#F3E6C6`**：页面与图表开放底色；
- **墨黛 `#28231B`**：正文、标题、坐标轴、关键结构；
- **石青 `#006F91`**：第一主系列、核心关系、深度；
- **石绿 `#2F8456`**：第二主系列、主体与自然层次；
- **金 `#B97A12`**：比较层、次级强调、重要节点；
- **朱砂 `#C44530`**：异常、转折、风险和少量提醒；
- **紫 `#704C99`**：类别身份确有需要时的第五色，不作为默认主色。

## 三种配色政策

### 单一主色优先

适用于简单趋势、排名、分布和关系图。选择石青或石绿作为主色，其余内容使用墨黛、规则线和开放填充。

### 两种主色上限

适用于二元比较、正负偏差、焦点与背景、基准与实际。最多两种非中性色，并使用直接标注、线型或符号区分。

### 多类别放宽

只有类别身份本身重要时才使用多色，最多五种。超过五类时保留前几类并合并“其他”，或改用小多图和直接标注。

## 朱砂规则

朱砂不是通用装饰色，也不默认表示“下降”。它只用于真正需要读者停下来的转折、异常、风险或例外。一个图表中通常只应有一个朱砂重点。

## 禁止做法

- 不以颜色作为唯一的系列或状态区别；
- 不使用任意渐变填充图形；
- 不把青绿色铺成影响数据阅读的装饰背景；
- 不默认使用红涨绿跌或红绿正负；
- 不为了“丰富”而给每一根柱子不同颜色；
- 不擅自宣称色值是《千里江山图》的精确颜料采样。
