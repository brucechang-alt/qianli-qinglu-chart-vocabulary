# 千里青绿数据可视化词汇 2.0

> 色彩提纯版：保留青绿山水的层次，把图表标记色恢复到更明亮、更清楚的屏幕表达。

![千里青绿数据可视化词汇预览](assets/qianli-qinglu-preview.jpg)

这是一套从中国青绿山水获得色彩启发的现代数据可视化体系。2.0色彩提纯版包含9类信息关系、67种可编辑SVG图形、一张高清总表、可编辑HTML源文件和一组可直接用于网页或设计软件的色彩变量。

## 为什么做这套体系

我们从北宋王希孟《千里江山图》的石青、石绿、金色与墨色层次出发，把青绿山水鲜明而有秩序的色彩关系，转译成适用于新闻报道、研究报告、课程和商业分析的数据语言。参考原画保持原样；图表采用独立的高纯度屏幕色，不把古画当前的泛黄和褪色状态误当成初始色彩。

这不只是给图表换一组颜色。选择图表时，先判断读者需要理解的关系，再在相应家族中选择图形。颜色始终配合位置、线型、符号、排序和直接标注，不作为唯一的信息编码。

## 包含什么

- 9类信息关系：随时间变化、排名、偏差、量级、分布、相关性、部分与整体、流动与关系、空间；
- 67个可单独下载和修改的SVG图形；
- `assets/qianli-qinglu-poster.png`：高清总表；
- `src/qianli-qinglu-chart-vocabulary.html`：可编辑总表源文件；
- `charts/manifest.json`：完整图形目录；
- `tokens/qianli-qinglu-colors.json`：配色变量和使用角色；
- `docs/`：图表选择、色彩和署名指南。

## 快速使用

1. 打开 `index.html` 浏览全部图形；
2. 在页面中按关系家族筛选；
3. 下载相应SVG并替换文字、数值和标签；
4. 依据 `docs/color-usage-guide.md` 保持配色角色；
5. 发布时按 `docs/attribution-guide.md` 保留必要署名。

## 核心配色

| 角色 | 色值 | 建议用途 |
|---|---:|---|
| 素绢 | `#FAF2D9` | 页面底色、开放填充 |
| 墨黛 | `#1C211D` | 文字、坐标、结构锚点 |
| 石青 | `#007EA7` | 主系列、深度、核心关系 |
| 石绿 | `#259B62` | 主体、增长、自然层次 |
| 金 | `#D99A16` | 比较层、次级强调 |
| 朱砂 | `#E14B32` | 转折、异常、风险提醒 |

高纯度色只承担柱、线、点、面积和分类。小号彩色文字改用同色相深阶色，以确保素绢底上的阅读对比度。
